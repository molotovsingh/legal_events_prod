# Bug Report — No Validation of upload_urls Count vs Selected Files

Date: 2025-11-06
Timestamp: 2025-11-06T01:20:10Z (UTC)
Author: Codex CLI assistant

## Summary

The UI assumes the number of presigned URLs returned by `/v1/runs` equals the number of selected files and indexes them directly. It fails silently if counts differ.

## Evidence
- frontend/index.html:261–269 — `const uploadUrls = runResponse.data.upload_urls;` then loops files and uses `uploadUrls[i]` without bounds checking.

## Impact
- Upload failures or partial uploads without a clear error; later processing fails.

## Recommended Fixes
- Validate counts: if `uploadUrls.length !== files.length`, show a clear error and abort.
- Render per-file upload status, and retry failed PUTs.

## Validation Steps
1) Simulate the API returning fewer URLs; UI should error clearly and not proceed to start the run.
2) When counts match, uploads and processing proceed.
