# Bug Report — Long Event Text Overflows Table Cells (UX)

Date: 2025-11-06
Timestamp: 2025-11-06T01:20:24Z (UTC)
Author: Codex CLI assistant

## Summary

Event particulars and citations can be very long; the table view renders full strings in a single row, which can overflow or cause horizontal scrolling.

## Evidence
- frontend/index.html:432–439 — Renders entire fields inside table cells without truncation.

## Impact
- Poor readability; layout breaks on smaller screens.

## Recommended Fixes
- Truncate long text with CSS (ellipsis) and provide a tooltip or “expand” to view full content.
- Optionally add a modal or details panel to view the selected event.

## Validation Steps
1) Load events with long particulars; table remains readable with truncation.
2) “Expand” or tooltip reveals full text on demand.
