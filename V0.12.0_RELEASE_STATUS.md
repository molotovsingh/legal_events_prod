### New Dependencies Added

```python

tiktoken>=0.7.0          # ~1MB   - OpenAI GPT tokenizer

sentencepiece>=0.1.99    # ~2MB   - Llama tokenizer dependency
```

### Docker Image Size Impact

**Current Image Size:** ~500MB (estimated, API + worker services)
**Projected Image Size:** ~1.8GB (with transformers + PyTorch)

**Breakdown:**
| Component | Size | Required For |
|-----------|------|--------------|
| Base Python 3.11 | ~200MB | All deployments |
| Application Code | ~50MB | All deployments |
| Core Dependencies | ~250MB | All deployments |
| tiktoken | ~1MB | GPT models (OpenAI, OpenRouter GPT) |
| transformers | ~500MB | Llama models (OpenRouter Llama) |
| PyTorch (transformers dep) | ~800MB | Llama models |
| sentencepiece | ~2MB | Llama models |
| **TOTAL** | **~1.8GB** | Full feature set |

### Mitigation Strategy: Optional Dependencies

**Recommendation:** Make transformers optional, document deployment options

**Option A: Full Feature Set (Recommended for Production)**
```dockerfile
# Dockerfile
RUN pip install -r requirements.txt  # Includes transformers
# Image size: ~1.8GB
# Supports: GPT (OpenAI, OpenRouter), Llama (OpenRouter), Claude (Anthropic)
```

**Option B: GPT-Only Deployment (Lightweight)**
```dockerfile
# Dockerfile.lite
RUN pip install -r requirements.txt --exclude transformers sentencepiece torch
# Image size: ~500MB
# Supports: GPT (OpenAI, OpenRouter), Claude (Anthropic)
# Limitation: Llama models will raise TokenizerUnavailable
```

**Option C: Pre-downloaded Tokenizers (Fast Startup)**
```dockerfile
# Dockerfile
RUN pip install -r requirements.txt
RUN python -c "from transformers import AutoTokenizer; AutoTokenizer.from_pretrained('meta-llama/Meta-Llama-3.1-8B')"
# Image size: ~2.3GB (+500MB for tokenizer files)
# Benefit: No network dependency on first run
```

**Decision Needed:** Nov 15, 2025 (before Docker build testing)

### Startup Time Impact

**Estimated Startup Time:**
- Without transformers: ~5 seconds (current baseline)
- With transformers (lazy load): ~8 seconds (+3s for import)
- With pre-downloaded tokenizer: ~8 seconds (no download delay)
- With transformers (first-time download): ~30-60 seconds (HuggingFace download)

**Mitigation:** Use Option C (pre-download) for production deployments
