## What's New in v0.12.0

### 1. Pre-Run Cost Estimation ✅
- Upload documents and get accurate cost estimate BEFORE processing
- Shows exact input token counts using provider-specific tokenizers
- Displays per-document breakdown and total cost
- Frontend button: "Estimate Cost" with live preview

### 2. Post-Run Token Tracking ✅
- Detailed token usage captured during processing (prompt + completion)
- Persisted as artifact for audit trail
- Displayed in run details modal
- Supports both event extraction and classification tracking

### 3. Classification Layer (Layer 1.5) ✅
- Optional document classification before event extraction
- Categorizes documents (Contract, Notice, Motion, etc.)
- Configurable model selection
- Results stored as artifact and displayed in UI

### 4. New API Endpoints ✅
- `POST /v1/estimate-tokens` - Pre-run cost estimation
- `GET /v1/classifiers` - List available classification models
- `GET /v1/runs/{run_id}/token-usage` - Post-run usage details
- `GET /v1/runs/{run_id}/classification` - Classification results

## Major Decisions Needed

### Decision 1: Transformers Dependency (HIGH PRIORITY)
**Question:** Make transformers optional or required?
**Impact:** Docker image size (+1.3GB if required)
**Options:**
- A) Required (simpler, supports all models)
- B) Optional (smaller image, Llama support conditional)
- C) Pre-download tokenizers (fast startup, +500MB image)

**Recommendation:** Option B (Optional) - Most flexible

### Decision 2: Adapter Coverage (MEDIUM PRIORITY)
**Question:** Add token extraction to Anthropic/OpenAI adapters in v0.12.0?
**Impact:** Complete vs partial token tracking
**Options:**
- A) Audit and fix all adapters now (adds 2 hours)
- B) OpenRouter only, defer others to v0.12.1

**Recommendation:** Option B (Defer) - Ship faster

### Decision 3: Pricing Freshness (MEDIUM PRIORITY)
**Question:** How to handle stale pricing data?
**Impact:** Cost estimate accuracy over time
**Options:**
- A) Static pricing + disclaimer (current)
- B) Periodic refresh from OpenRouter API (adds complexity)
- C) "Last updated" timestamp (transparency)

**Recommendation:** Option C (Timestamp) - Quick win
