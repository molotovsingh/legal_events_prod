**Result:** ✅ Database authentication successful

### Issue B: MinIO Timeout Parameter Not Supported
**Error:** `TypeError: Minio.__init__() got an unexpected keyword argument 'timeout'`
**Root Cause:** MinIO Python SDK version doesn't support `timeout` parameter
**Fix:** Removed `timeout=Timeout(...)` from Minio() initialization in `infra/storage.py:44-49`
**Result:** ✅ MinIO client initialized successfully

### Issue C: URL Parsing Edge Case
**Error:** `urllib3.exceptions.LocationValueError: No host specified.`
**Root Cause:** `urlparse('minio:9000')` treats 'minio' as URL scheme, returning empty netloc
**Fix:** Updated `_normalize_endpoint()` to only strip 'http'/'https' schemes:
```python
def _normalize_endpoint(self, endpoint: str) -> str:
    parsed = urlparse(endpoint)
    if parsed.scheme in ('http', 'https'):
        return parsed.netloc
    return endpoint  # Keep "minio:9000" as-is
```
**Result:** ✅ Endpoint parsing working correctly
